# MealWise

Sve naredbe pokretati iz root-a repozitorija.

Za pokrenuti prilikom developmenta:

- `npm run dev`

Za pokrenuti u produkciji:

- `npm run build`
- `npm run start`

Lint i formatiranje:

- `npm run lint`
- `npm run format`

Formatiranje bi se trebalo i automatski pokrenuti prilikom svakog commita.
